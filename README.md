# AIBB (AI BunkerBuster)

AI 기반 웹 애플리케이션 취약점 자동 공격 및 분석 시스템

## 팀원
- **교준**: Docker 환경 구축 & 공격 환경 관리
- **용빈**: LLM Engine & 피드백 루프
- **영주**: Scanner & CVE 탐지
- **세현**: Prompt Engineering & 템플릿 관리

## 프로젝트 구조
```
ai-pentester/
├── targets/          # CVE 테스트 환경
├── modules/          # Python 모듈
├── config/           # 설정 파일
└── docs/             # 문서
```
